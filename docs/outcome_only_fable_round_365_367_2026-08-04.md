# Outcome-only Fable invention round: candidates 365--367

Date: 2026-08-04.

## Design

Three independent maximum-effort `claude-fable-5` sessions received an
outcome-only brief containing the unseen-class retrieval problem, audited
comparison lanes, corrected local In-Shop references, and the requirement to
invent something better. They were forbidden to read the repository candidate
catalogue, stopping adjudication, candidate files, or prior Fable outputs before
fixing one proposal. Each proposal was frozen before a separate collision audit.

This directly tests the concern that giving an inventor suggested mechanisms or
the long failure catalogue can anchor it. The successful brief is committed at
`docs/fable_unbiased_research_brief_2026-08-04.md`.

## Results

| candidate | independent proposal | post-freeze verdict |
| --- | --- | --- |
| 365 | Blind-Subspace Allocation | no measured provenance; weighted direct-sum subspaces + shared/private decomposition + residual relational distillation; shared-backbone interference invalidates its strongest guarantee |
| 366 | Reliability-Gated Descriptors | generic hubness premise contradicted by corrected measurements; ordinary learned Euclidean descriptor + occupied uncertainty head + listwise NCA + invariance regularizer |
| 367 | Composite Class Expansion | exact rediscovery of binding-error composite candidate 210; CutMix/Metrix + Proxy Synthesis/virtual classes |

All three failed before diagnostic or GPU. All three forecast gains only over a
weaker fixed-recipe baseline and explicitly failed to predict an absolute score
above the audited external horizon. Sessions 366 and 367 additionally failed to
locate VAPNet even though the brief gave its exact paper title and venue; the
primary NeurIPS 2023 source verifies it, so the horizon was not lowered.

## Interpretation

The round does not prove that no novel method exists. It supplies stronger
evidence for the bounded stopping claim: removing catalogue anchoring generated
three materially different surface forms, but their executable atoms still
landed independently in operator families already occupied by primary art and
the catalogue. The obstacle is not that the model was told which ideas failed.
It is that common training referents—proxies, model similarities, uncertainty
heads, mixed samples, and virtual classes—route to established supervision and
comparison operators.

No GPU run is scientifically licensed by this round. The next reopening event
must be either (a) a new corrected measurement that identifies an outcome-relevant
training observable not already routed to an occupied action, or (b) a primary
source correction that vacates a load-bearing occupancy ruling. Repeating the
same outcome-only prompt again has declining information value after three
independent collisions.
