## Closest candidate and why it still fails

Candidate 327 is the narrowest residual. Snorkel establishes that labeling-
function accuracies and dependencies can be estimated without ground-truth
labels, and weakly supervised metric learning consumes pair/tuple labels. A
fresh search found no primary paper that makes the exact combination of
Snorkel-style agreement moments and DML pair eligibility load-bearing. That
absence is not a novelty proof, and it is not needed for the verdict: after the
label model, the learning operator is still soft pair weighting, a family this
project has already reduced and tested repeatedly. Calling the label generator
new would not make the similarity-learning mechanism new.

Candidate 325 has the same distinction. Group synchronization and invariant/
equivariant representation learning are established independently. A fresh
search found no primary source for the exact phrase "angular synchronization
for DML", but the proposed synchronizer only estimates the view variable fed
to an occupied view-aware selection/projection rule. The reduction kills the
candidate without relying on an absence claim.

## Structural conclusion and reopening condition

This batch independently reconverges on audits 321--323. Static embedding,
proxy, and label feedback is Gram-invariant; scalar actions become weighting,
mining, or regularization. Estimating a latent factor more cleverly does not
change the supervision relation that consumes it. The one interface that did
change the relation, positive-to-unknown replacement, has measured
self-erasure on corrected In-Shop.

The next justified action is therefore not a ninth analogy inside the same
operator box. Reopening requires either (1) a new, independently validated
non-Gram observation that specifies a target relation before implementation,
or (2) an explicit change of claim such as auditable train-split-only visual
pretraining, new annotations, multi-vector deployment, or transductive
retrieval. Strong-baseline reproduction remains necessary infrastructure but is
not a novelty candidate.
