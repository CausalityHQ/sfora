# CFR — Clifford Fiber Rectification

**Lane: A** (ResNet-50, 512-D normalized descriptor, ~224 px, single-view cosine retrieval, 200 epochs). All forecasts and comparisons below are in Lane A only.

**One-sentence mechanism.** Train the encoder so that within-class variation of the deployed descriptor is generated by a *fixed, identity-independent maximal Hurwitz–Radon frame field* on the descriptor sphere — the maximal system of pointwise-orthonormal linear vector fields that exists on `S^511` — so that nuisance acts on the descriptor as an **exact isometry shared by all identities** (multiplicatively, as a group) instead of as a **class-independent additive offset**, and its common-mode component cancels *exactly* in cosine similarity for seen and unseen identities alike.

## 1. Executable mathematics

### 1.1 The fixed geometric constant (zero learned parameters)

Build a maximal anticommuting family `A_1..A_17 ⊂ so(512)` satisfying

```
A_kᵀ = −A_k ,   A_k² = −I_512 ,   A_k A_l = −A_l A_k  (k ≠ l)
```

Such a family exists with exactly `ρ(512) − 1 = 17` members. (Radon–Hurwitz: `512 = 2^9`, `9 = 4·2+1` ⇒ `ρ = 8·2 + 2^1 = 18`; Adams' theorem makes `ρ(d)−1` the maximum number of pointwise-independent vector fields on `S^{d−1}`.) Explicit construction:

```
ε  = [[0,−1],[1,0]]            (2×2, skew, ε² = −I)
σ3 = diag(1,−1)                 (2×2, symmetric, σ3² = I)
L_1..L_7 ∈ R^{8×8}              left-multiplication by imaginary octonion units (Fano table)
                                → skew, L_i² = −I, L_iL_j = −L_jL_i

Cl(0,8) on R^16:   E_j = L_j ⊗ σ3  (j=1..7),   E_8 = I_8 ⊗ ε
                   ω  = E_1E_2···E_8       (ω ᵀ = ω, ω² = I, ω E_j = −E_j ω)

R^32  (m=9):   { ε ⊗ ω }  ∪  { I_2  ⊗ E_j }_{j=1..8}
R^512 (m=17):  { A'_i ⊗ ω }_{i=1..9} ∪ { I_32 ⊗ E_j }_{j=1..8}
```

Every factor is a **signed permutation matrix**, so every `A_k` is a signed permutation: the identities hold *exactly in floating point*, `A_k u` costs `O(d)` (a gather + sign flip) not `O(d²)`, and storage is `16 × 512` indices + signs ≈ **24 KB of non-trainable buffers**. Mandatory unit test in float64: `max|A_kᵀ + A_k| = max|A_k² + I| = max|A_kA_l + A_lA_k| = 0` exactly, all `k<l ≤ 17`. We use the first **m = 16**.

**Frame identities (proved, not approximated).** For any `u ∈ S^{511}`:

```
uᵀA_k u = 0            (skew)              → A_k u ∈ T_u S^{511}
‖A_k u‖ = 1            (A_kᵀA_k = I)
(A_k u)ᵀ(A_l u) = δ_kl (A_kᵀA_l + A_lᵀA_k = 0)
```

So `{A_1u,…,A_mu}` is an **orthonormal m-frame in the tangent space at every point**, with projector `Π(u) = Σ_k (A_ku)(A_ku)ᵀ`. For `‖a‖ = 1`, `J_a = Σ_k a_k A_k` satisfies `J_a² = −I`, hence

```
R(a,θ) := exp(θ J_a) = cos θ · I + sin θ · J_a ∈ SO(512)      (closed form, exact)
```

The **fiber** through `u` is `F(u) = S^{511} ∩ span{u, A_1u,…,A_mu} ≅ S^m`, a great `m`-sphere; the fibers are Clifford-parallel and fiberwise homogeneous (for `m=1,3,7` these are literally the Hopf fibrations).

### 1.2 Theorem (exact common-mode nuisance cancellation)

> Let `z_i = R(a,θ) μ_i` and `z_j = R(a,θ) μ_j` for **any** unit `μ_i, μ_j` and **any** shared `(a,θ)`. Then `z_iᵀz_j = μ_iᵀμ_j` exactly.

*Proof.* `R ᵀR = cos²θ I + cosθ sinθ Σ_k a_k(A_k + A_kᵀ) + sin²θ Σ_{k,l} a_k a_l A_kᵀA_l`. The middle sum vanishes by skewness. For the last, `A_kᵀA_l = −A_kA_l`, so `Σ_{k,l}a_ka_l A_kᵀA_l = −[Σ_k a_k² A_k² + Σ_{k<l} a_ka_l(A_kA_l + A_lA_k)] = Σ_k a_k² I = I`. Hence `RᵀR = I` and `z_iᵀz_j = μ_iᵀRᵀRμ_j = μ_iᵀμ_j`. ∎

Nothing in this proof references class labels, class count, or the training split. **It holds verbatim at unseen-class means.** That is the entire transfer mechanism.

Two useful corollaries (same algebra):

- Same identity, different nuisance: `z_1ᵀz_2 = cos²θ + sin²θ (a_1ᵀa_2)` — for independent nuisance this is `cos²θ`, *identical to what an unconstrained model gets at matched intra-class angular spread*. Confinement costs nothing when `m` is large enough that the fiber is roomy.
- Different identity, different nuisance: `z_1ᵀz_2 = μ_1ᵀ R_1ᵀR_2 μ_2`, and `R_1ᵀR_2` depends only on the *relative* nuisance, never on identity.

### 1.3 Losses

Batch: `P` classes × `K = 4` images. `z_i ∈ S^{511}`, label `y_i`, class proxy `p_c ∈ S^{511}`.

Because `(A_k p)ᵀp = 0`, the frame coefficients of the tangential residual `w_i = z_i − (p_{y_i}ᵀz_i)p_{y_i}` are simply `c_{ik} = (A_k p_{y_i})ᵀ z_i`.

**Capped explained energy** (`κ = 2/m`, denominator floored *and detached*, `τ = 0.25`):

```
D_i = stopgrad( max(‖w_i‖², τ²) )
Ê_i = Σ_{k=1}^{m} min( c_{ik}² , κ · D_i )
```

**Φ — fiber confinement.** Proxy-anchored and pair-anchored forms (`η = 0.2`):

```
Φ_prox = mean_i  ( (1−η) − Ê_i / D_i )_+

for same-class ordered pairs (i,j):
   w_ij = z_j − (z_iᵀz_j) z_i ,  c_ijk = (A_k z_i)ᵀ z_j ,  D_ij = stopgrad(max(‖w_ij‖², τ²))
Φ_pair = mean_{(i,j)} ( (1−η) − Σ_k min(c_ijk², κD_ij) / D_ij )_+
```

**Ω — fiber inertness across identities.** Let `𝔅 = {A_k}_{k≤m} ∪ {A_kA_l}_{k<l}` (`|𝔅| = 16 + 120 = 136`; every element is again a signed permutation with `XᵀX = I`, and `{A_kA_l}` spans the Lie algebra of the group generated). For different-class sample pairs and different-class proxy pairs:

```
Ω = mean_{y_i ≠ y_j} (1/|𝔅|) Σ_{X∈𝔅} (z_iᵀ X z_j)²
  + mean_{c ≠ c'}    (1/|𝔅|) Σ_{X∈𝔅} (p_cᵀ X p_{c'})²
```

(On SOP/In-Shop subsample 512 proxies per step.)

**Total.**

```
L = L_base + λ_f(t) · ( Φ_pair + ½ Φ_prox ) + λ_o · Ω
λ_f(t) = 1.0 · clip((t − 5)/10, 0, 1)      # ramp over epochs 5→15
λ_o    = 5.0 ,  η = 0.2 ,  κ = 2/m ,  m = 16 ,  τ = 0.25
```

**Gradient paths.** `L_base` → backbone `θ`, embedding `W`, proxies `P` (unchanged). `Φ` → `θ, W, P` through `z_i`, `z_j`, `p_c`, and through `Ê` only (the denominator `D` is detached and floored, see §2). `Ω` → `θ, W, P` through both arguments. `A_k` are constant buffers, `requires_grad=False`, never updated, never deployed.

**Multi-proxy bases.** If `L_base` uses `M > 1` proxies per class, anchor `Φ_prox` at the soft-assigned proxy `p̄_c(x) = Σ_k w_k p_{c,k} / ‖·‖`, `w = softmax(γ zᵀp_{c,k})`, `γ = 10` (matching the soft-assignment already used by multi-proxy losses). `Φ_pair` and `Ω`'s sample term need no proxies at all.

## 2. Causal zero-shot error mode + proof-level degeneracy attack

### 2.1 The error mode: systematic additive nuisance bias

Model an unconstrained descriptor as `z = cos θ · μ_c + sin θ · n`, with `n` the nuisance displacement. Empirically `n` is **class-independent given the nuisance state** (pose/lighting/crop are generic feature-map properties): two *different* identities photographed in the same pose receive nearly the *same* additive displacement.

Worked instance, `θ = 30°`, `α = μ_1ᵀμ_2 = 0.70` (a plausible fine-grained unseen pair):

| | unconstrained | CFR |
|---|---|---|
| same identity, independent nuisance | `cos²θ = 0.750` | `cos²θ + sin²θ(a_1ᵀa_2) = 0.750` |
| **different identity, same nuisance** | `cos²θ·α + sin²θ = 0.775` ✗ **inverted** | `α = 0.700` ✓ (exact, Thm 1.2) |

Why seen-class training does not fix this in a transferable way: the loss can eliminate the inversion by driving `sin θ → 0` — i.e. by **deleting the nuisance-sensitive features from the backbone**. That is the cheapest descent direction, it is class-specific, and it destroys exactly the features unseen classes may need. CFR offers a second, transferable descent direction: keep `sin θ`, route the variation into the frame, and the inflation cancels algebraically.

**Sober statement of the leverage.** The theorem is exact only for *shared* nuisance. When nuisance states differ by `Δa`, the residual inflation is `cosθ sinθ · ‖Δa‖ √m · β + sin²θ · ‖Γ‖_op`, with `β = max_{k,c≠c'}|μ_cᵀA_kμ_{c'}|` and `Γ` the second-order coherence matrix — both driven by `Ω`, both floored near the random-vector level `1/√d ≈ 0.044`. With `C(C−1)/2 · |𝔅| ≫ C·d` constraints, `Ω` cannot drive these to zero; expect `β ≈ 0.025–0.035`. **So the honest claim is not "nuisance is eliminated" but "a systematic, class-independent bias on cross-identity similarity is converted into a zero-mean fluctuation of comparable magnitude."** A `+0.19` systematic shift on the same-nuisance subset of the gallery is far more damaging to R@1 than a `±0.07` zero-mean term (which merely widens `σ_neg` from ~0.10 to ~0.12). That conversion is the mechanism's real leverage, and it is what the forecasts in §5 are sized against.

### 2.2 Degeneracies, and why each is excluded

**D1 — Class collapse (`w_i → 0`).** *Excluded by construction, not by a penalty.* `D_i = stopgrad(max(‖w_i‖², τ²))` has **no gradient path**, so `∂Φ/∂‖w_i‖ ≡ 0`: shrinking the residual cannot reduce `Φ`. Furthermore, when `‖w_i‖ < τ` the denominator is pinned at `τ²`, so `Ê_i/D_i ≤ ‖w_i‖²/τ² < 1`, and `Φ` becomes *strictly increasing as the class collapses*. Collapse is not merely unrewarded; it is punished. No separate variance-floor loss is required.

**D2 — Cramped fiber (all residual energy in one frame direction).** Blocked by the per-direction cap: `Σ_k min(c_k², κD) ≤ mκD`, so reaching `Ê/D ≥ 1−η = 0.8` with `κ = 2/m = 0.125` requires **at least `⌈0.8/0.125⌉ = 7` frame directions to be active**. This matters because a 1-dimensional fiber forces same-class points onto a great circle, where `±θ` spread costs `cos 2θ` instead of `cos²θ` (0.50 vs 0.75 at `θ=30°`) — a cramped fiber is strictly worse than no constraint.

**D3 — Frame abuse (explaining identity as nuisance).** If `μ_{c'} ∈ span{μ_c, A_1μ_c,…,A_mμ_c}`, a nuisance motion of class `c` lands on class `c'`. Bound: for `z = R(a,θ)p_c`, `|zᵀp_{c'} − cosθ·p_cᵀp_{c'}| ≤ sinθ · √m · β`. A ranking flip against margin `Δ` requires `sinθ √m β > Δ/2`; at `θ=30°, m=16, Δ=0.9` this needs `β > 0.45`, i.e. **~10× above the random-init level of `1/√512 = 0.044`**. `Ω` drives `β` *down*, so D3 is excluded with an order of magnitude of headroom. (Prediction: `Ω` is nearly inactive — verified by F8.)

**D4 — "Just rotate `W`" / a learned gauge would be needed.** *Excluded by an exact gauge theorem.* For any `Q ∈ O(512)`, the family `Ã_k = QA_kQᵀ` is again Hurwitz–Radon, and `Ã_k(Qz) = Q(A_kz)`. Every term in `L` is built from inner products, all of which are `Q`-invariant. Hence `L(A, W) = L(QAQᵀ, QW)` **identically**: the coordinate-aligned canonical family is WLOG, and a learned `Q` is provably redundant with the already-learned `W`. This also answers "you just added parameters": there are none.

**D5 — Trivial satisfiability.** For a random 16-dim subspace of the 511-dim tangent space the unexplained fraction is `1 − 16/511 = 0.969`. Requiring `≤ η = 0.20` is a reduction by a factor of ~4.8. The constraint is not vacuous.

**D6 — Memorization instead of structure.** The constraint is re-imposed on freshly augmented views every epoch and is enforced *per sample* against a persistent proxy, so it binds on the functional map, not just on 30 stored points. F4 (§5) falsifies the memorization reading directly by measuring the structure on held-out classes.

| Work | Distinction |
|---|---|
| **PFML**, Bhatnagar & Ahuja, CVPR 2025 (the Lane A frontier) | PFML replaces the pairwise interaction *kernel* with a distance-decaying potential over samples and 15/15/2 proxies per class; CFR leaves the base interaction untouched and instead constrains *which tangent subspace intra-class variation is allowed to occupy* — the two compose. |
| **DADA**, Data-Augmented Domain Adaptation, AAAI 2024 | DADA closes the sample↔proxy *distribution* gap with adversarial domain/category discriminators and Beta-mixed intermediate features; CFR adds no adversary, no discriminator, and no synthesized features, and targets nuisance geometry rather than the data/proxy domain gap. |

| **Non-isotropy Regularization (NIR)**, CVPR 2023 | NIR uses a normalizing flow to make each proxy-conditional sample distribution non-isotropic and *unique per proxy*; CFR's frame is deliberately **shared and identity-independent** — uniqueness per class is precisely what would break transfer. |
| **Anti-Collapse Loss** (MCR²/coding-rate, TMM 2024), **Total Coding Rate / MCR²** | These maximize a scalar volume/rank functional of the embedding set; CFR imposes no rank objective and instead specifies the *subspace* variation must lie in — the m-sweep (C8) and C3 separate "more rank" from "this frame". |

| **HIER**, hyperbolic/hierarchical proxies; **S2SD**; **DiVA** | Hierarchy, self-distillation, and auxiliary SSL heads add supervision *targets*; CFR adds a geometric *constraint* with zero new targets, no extra heads, and no extra forward passes. |

- **F4** Unexplained fraction on held-out classes `> 0.85` ⇒ the fiber structure does not transfer; reject even if R@1 improves.
- **F5** `C4` or `C5` recovers `≥ 80%` of the gain ⇒ generic anti-collapse effect.
- **F6** `C7 (learned gauge) > CFR + 0.5` on CUB ⇒ the gauge theorem is practically irrelevant; the effect is optimization, not geometry.
- **F7** `m=1` does not underperform `m=16` by `≥ 1.0` ⇒ the fiber-roominess prediction fails.
- **F8** `β` on held-out classes `> 0.05` (i.e. `Ω` never gets below random level) ⇒ D3's headroom argument is unsupported.

## 6. Cost, benchmark and contamination risk

**Training cost.** Learned parameters added: **0**. Buffers: 16 signed permutations ≈ 24 KB, `requires_grad=False`. FLOPs: `Φ` is `O(m·B·d)`; `Ω` is a Gram over `|𝔅|=136` signed-permutation-transformed batches ≈ 1.0 GFLOP/step versus ≈ 1476 GFLOP/step for ResNet-50 at batch 120 forward+backward ⇒ **≈ 0.07% overhead**; ≈ 0.15% on SOP with 512 subsampled proxies. Activation memory: `m·B·d·4B ≈ 3.9 MB`. No extra forward passes, no second view, no auxiliary network, no adversary. **Deployment cost is byte-identical to the base:** one ResNet-50, one 512-D descriptor, cosine NN; `A_k` and proxies are discarded.

**Method risks (stated plainly).**
1. The structural hypothesis may be too strong: descriptor-level nuisance may simply not be a 16-dim isometric orbit. Symptom: `Φ` plateaus near initialization and the gain is < 1.0. Hedges: `η = 0.2` slack, the `m`- and `η`-sweeps.
2. SOP and In-Shop have ~5 images/class; the pair term has few pairs and `C ≫ d` removes the rank-starvation channel entirely. Smaller gains there are *predicted*, not excused — and a generic regularizer would not show this pattern.
3. Warm-up interaction: during the 5 frozen-backbone epochs the constraint can be satisfied by rotating `W` alone, locking a poor alignment. Hedge: `λ_f` ramps 0→1 over epochs 5–15.
4. Multi-proxy anchoring (soft-assigned `p̄_c`) is an unvalidated design choice; PFML+CFR gains may be smaller than forecast.
5. `Ω` is over-determined (`C²|𝔅| ≫ Cd`); the second-order guarantee is weak by construction. F8 tests it.
6. **My class-holdout HP protocol is nonstandard in this literature**, where hyperparameters are conventionally selected against the test split. This biases my B0/B1 numbers *downward* relative to published ones and therefore works against me in the frontier arithmetic. I flag it rather than quietly adopting the field's protocol.

**Benchmark and contamination risk.**
- ImageNet-1K initialization is a shared confound across every Lane A reference: ImageNet contains ~59 bird classes plus car and product categories, with documented image-level overlap with CUB. CFR introduces **no new external knowledge** — the `A_k` are mathematical constants containing zero data, so the method adds no contamination surface.
- No test data, no generated data, no text/VLM encoders, no extra annotations, no transduction, no reranking, no test-gallery fitting, single view, single descriptor. All diagnostics run on held-out *training* classes.
- CUB test = 5,924 images / 100 classes ⇒ 1.0 R@1 point ≈ 59 images; Cars196 at 92.7 is near saturation, where a +0.6 crossing is ~1.2% relative error reduction — comparable to split and tuning noise. All four benchmarks are single-split with no conventional validation set; reported ±0.5 gains in this literature are not reliably distinguishable from tuning noise. Mitigations: 5 seeds, seed-paired comparisons, and the class-holdout protocol.

## 7. Baseline reduction, recipe, and unresolved source ambiguities

**PFML (Bhatnagar & Ahuja, CVPR 2025) — reduction as disclosed.**

```
U = Σ_i Ψ_{y_i}(z_i) + Σ_j Σ_k Ψ_j(p_{j,k})

ψ_att(r, z_i) = −1/δ^α           if ‖r − z_i‖₂ < δ ,  else  −1/‖r − z_i‖₂^α
ψ_rep(r, z_i) = +1/‖r − z_i‖₂^α  if ‖r − z_i‖₂ < δ ,  else  +1/δ^α

α ∈ {0,…,6} (cross-validated) ;  δ ∈ [0.1, 0.3]
M = 15 proxies/class (CUB, Cars) ; M = 2 (SOP)
ResNet-50, 512-D, 224×224, Adam, lr 5e-4 backbone / 0.05 proxies (100×), 200 epochs
R@1 over 5 runs: CUB 73.4 ± 0.3, Cars 92.7 ± 0.3, SOP 82.9 ± 0.2
```

**Proxy-Anchor (Kim et al., CVPR 2020) — official R50/512 commands as disclosed:**
CUB `batch 120, lr 1e-4, warm 5, bn-freeze 1, lr-decay-step 5` → R@1 **69.9**; Cars same with `lr-decay-step 10` → **87.7**. SOP/In-Shop official commands use **Inception-BN** (79.2 / 91.9).

**Unresolved source ambiguities — every downstream claim is contingent on resolving these:**

1. **PFML:** batch size, weight decay, sampler/IPC, and the *per-dataset* values of `α` and `δ` are not stated in what I could read; whether embeddings are L2-normalized before the Euclidean potential is not explicit; the exact composition of `Ψ_c` (which sources are attractive vs repulsive, whether proxies act as field sources on other proxies) is not fully pinned down. **PFML+CFR (B1 row) is contingent on resolving these from the paper or code.**
2. **PFML does not report In-Shop.** The Lane A In-Shop reference is PA+DADA at 93.0 with **unreported seed count and σ**, so no principled crossing bar exists there.
3. **No published R50/512 Proxy-Anchor numbers for SOP or In-Shop** in the official README — my B0 rows for those two datasets forecast an unpublished configuration.
4. **PA's optimizer, weight decay, epoch count, `α`, margin `δ`, and IPC are code defaults I did not read** (I am blind to the filesystem and did not fetch the source). My assumed values (AdamW, wd 1e-4, `α=32`, `mrg=0.1`, 60 epochs, `lr-decay-gamma 0.5`) must be verified against the official code before any matched claim is made.
5. **Lane A mandates 200 epochs; PA's official schedule is 60 epochs with step decay.** All my arms therefore run 200 epochs with cosine decay, which is a *changed recipe*. I report both `PA@200-cosine` (the matched control) and `PA@60-official` (the published anchor, expected 69.9 / 87.7) and never inherit a published number under a schedule I altered.
6. **DADA's 1.06× epoch-time / 1.01× memory figures** come from an appendix I could not read; I take them as given from the brief.
