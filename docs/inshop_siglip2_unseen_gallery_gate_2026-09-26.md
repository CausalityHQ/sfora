# In-Shop unseen-gallery training gate, 26 September 2026

The previous 128-D SigLIP2 bank candidate scored 95.4823% packed Recall@1 on official In-Shop query/gallery, below the dated UNICOM 96.7% reference. Its original TRAIN holdout overpredicted performance because the full TRAIN gallery contained fit-class distractors seen during training. [Evidence and diagnostic](inshop_siglip2_official_result_2026-09-25.md) establish the need for a gallery whose identities are all unseen during training. Official query/gallery labels and scores cannot select the new recipe.

The [frozen TRAIN-only preflight](evidence/compact_metric/sop-siglip2-substrate-v1/inshop-unseen-gallery-preflight-v1.json) divides 3,997 TRAIN products by a fixed identity hash, reserving every singleton for fit. It yields **13,283 fit images / 2,004 fit products** and **12,599 held images / 1,993 held products**. The held gallery is only 13 images smaller than the official 12,612-image gallery. All held images are symmetric queries with self excluded. This matches gallery size and identity novelty, though the official protocol is asymmetric and has more query/gallery products; only paired arm differences can select a method. Partition SHA-256 `cfada103c44df866db5e2ee9ecc2301ca691a4d0cdb3c875fe4051b62570894c`; preflight receipt SHA-256 `d5e22c6a331acbdf3b143b9836597593c2317f9488b99b72f61a4c54baf18eb8`.

The source-bound new trainer keeps the SigLIP2 Large/256 backbone, PCA-initialized 128-D head, 130-byte packed scorer, ArcFace coefficient and margin, detached member-bank SmoothAP coefficient 8, augmentation, AdamW rates/decay, BF16 precision, batch64 coverage-first identity schedule, singleton rank skip, and seed179023. The first 1,000 batches are identical in all arms. Three serial arms answer distinct questions:

| Arm | Change from control | TRAIN-only decisive readout |
| --- | --- | --- |
| control | 1,000 updates | baseline packed Recall@1 and mAP@R on the 12,599-image unseen gallery |
| freeze | 1,000 updates; freeze vision blocks 0–11 | same data and budget; tests whether preserving early pretrained features helps unseen identities and saves training time |
| budget | 3,000 updates; same trainable parameters | first 1,000 batches match control; tests whether undertraining explains the quality ceiling |

The prior fit saturation and block drift screens did not kill either arm: fit leave-one-out Recall@1 was 99.3613% (<99.5% threshold), and lower-block weight drift was 117% of upper (>25% threshold). The new gate uses product bootstrap on the paired per-query packed Recall@1 deltas. An arm advances only if its conditional 95% lower bound exceeds zero, mAP@R is no more than 0.005 below control, and training remains finite with complete source, schedule, checkpoint, memory and wall receipts. The one-seed gate is exploratory; a winner must replicate on independent seeds before algorithmic claims. If neither arm passes, no official read is repeated; diagnose final trained width/resolution or the local reproduction gap. If an arm passes, fix it using TRAIN only, then retrain on all official TRAIN products before the next clearly labelled exploratory official read. Native and full pipeline latency remain separate gates.

The 17-update [control](evidence/compact_metric/sop-siglip2-substrate-v1/inshop-unseen-control-smoke17-v1.json) and [freeze](evidence/compact_metric/sop-siglip2-substrate-v1/inshop-unseen-freeze-smoke17-v1.json) smokes completed with finite loss, 17 rank-active updates, and identical split, schedule, source, model, and first-ten input hashes. Control took **21.694 s / 22,043,853,312 peak CUDA bytes**; freeze took **18.870 s / 17,615,487,488 bytes**. The checkpoint audit against the pinned pretrained vision model found that all **192 tensors in blocks 0–11 were bit-identical** under freeze and all **192 changed** under control; all 192 tensors in blocks 12–23 changed in both arms. The smoke receipt SHA-256 values are `b7b946b701ac102fda1fb06a758f0a13c523fd8ff941669dcda812801eccd7e3` and `cdb7c2c2b23baaf61c048d076d7c7f1518f256ec727511a72cfeaec33ff2fcde`. These are functional and resource checks, not quality measurements.

The complete one-seed [control](evidence/compact_metric/sop-siglip2-substrate-v1/inshop-unseen-control-179023-v1.json) and [freeze](evidence/compact_metric/sop-siglip2-substrate-v1/inshop-unseen-freeze-179023-v1.json) receipts have matching source, split, first-ten inputs, and 1,000-update schedule. On the TRAIN-only held gallery, packed Recall@1 was **98.3173% → 98.5951%** and mAP@R **0.82700 → 0.84049**. The frozen product bootstrap for the paired Recall@1 gain gave **+0.2778 percentage points**, conditional 95% interval **[+0.0961, +0.4648] points**, and the mAP@R delta was **+0.01350**. Training wall including bank initialization was **1,143.605 → 982.835 s** for 64,000 sampled images; peak allocated CUDA memory was **22,553,846,784 → 18,125,480,960 bytes**. Freeze clears its one-seed screen; the budget arm and final selector are still pending.
