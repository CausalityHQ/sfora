# In-Shop coordinate-subspace bank gate, 26 September 2026

This is an exploratory TRAIN-only structural-objective experiment, not an official or SOTA claim. The prior pretrained-feature hard-product subset failed its frozen miss-enrichment gate, so it cannot select this treatment. The readout is the complete 12,599-image, 1,993-product held gallery from the fixed In-Shop TRAIN split.

Use SigLIP2 Large/256, the same 128-D head, bank, augmentation, batch64 schedule, 1,000 updates, BF16, optimizer, 1e-5 vision rate, deployed 130-byte pack and exact scorer as seed-179024 control. Treatment alone samples a reproducible 64-of-128 coordinate subset at each update from a separate seed-specific CPU generator. It applies that same subset to ArcFace logits and to both anchors and detached bank rows in SmoothAP, renormalizing each subset before scoring. The full 128-D head and bank still update and deploy unchanged. This changes the training objective; the existing ArcFace `masks` parameter selects feature coordinates per class shard and does not itself mask the bank. No novelty claim follows from this experiment.

Gate, fixed before treatment results:

1. Serial 17-update control and treatment smokes on seed 179024: finite loss/gradients, no skipped steps, matching first-ten input, schedule, fit/held, PCA, pretrained model and source-file hashes. The new control must exactly reproduce the archived seed-179024 control checkpoint tensors and losses at 17 steps despite the trainer source increment. The treatment must change learned weights, use 64 coordinates each step, and stay within 10% of control wall and peak allocated CUDA memory.
2. If smoke passes, run only the 1,000-update seed-179024 treatment. Compare to the archived full seed-179024 control on the same complete held gallery with the existing paired product bootstrap. Advance only if the packed R@1 delta has a positive conditional 95% lower bound, mAP@R drops by no more than 0.005, and training wall and peak CUDA are each at most 10% above matched control. Require finite 1,000-step loss, complete source/checkpoint hashes and per-query vectors. If any condition fails, stop before seed 179025 and do not read official TEST.
3. If the first seed passes, repeat paired control/treatment on independent seed 179025 and require the same per-seed gate. Only then prepare a fresh unseen seed and a frozen pooled confirmation protocol before any official TEST read. A positive TRAIN-only result remains exploratory because the official query/gallery distribution differs.

The saved baseline control (seed 179024) is packed R@1 98.5554%, mAP@R 0.826739, 1,147.93 s including bank initialization per 64,000 sampled images, and 22.554 GB peak allocated CUDA on DGX Spark GB10. Its old trainer receipt and checkpoint are source-bound; the smoke replay audits behavioral identity under the new source. Serving format and scorer are unchanged by the treatment; image-to-top-k latency and official quality require separate validation if the quality gate passes.
