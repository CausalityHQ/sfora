# LOPS-PG: Leave-One-Out Positive-Safe Proxy Gradient

## Objective

Test a narrow train-time similarity-learning mechanism: retain Proxy Anchor's
global proxy signal while removing only the per-example embedding-gradient
component that would reduce cohesion with stopped same-class siblings.
Inference remains one normalized embedding and ordinary cosine similarity.

This is a prospective CPU mechanism test, not a SOTA claim. LE-IDGP is closed:
its density-gradient projection reduced hard-row margin in all four folds
(`-0.0001009480951448422` pooled; one-sided 99% lower bound
`-0.0001320963796106263`). The new mechanism does not use a density pool,
query/gallery data, or retrieval-time correction.

## Discovery disclosure

Fold 0 of the existing deterministic four-fold In-Shop train partition was
used for mechanism discovery. It contained 19 complete cohorts, 3,420 rows,
and 45 labels x 4 examples per cohort. No fold 1, 2, or 3 result was inspected.

On fold 0, the Proxy Anchor surrogate gradient conflicted with the proposed
positive-cohesion constraint on every row. Against unchanged PA under the same
`0.01`-radian single-anchor geodesic step, the proposed projection changed:

- hard-row retrieval margin by `+0.0006694638457456951`;
- nearest-positive similarity by `+0.0008610594085063561`;
- absolute nearest-positive similarity by `+0.000011773839926716526`, versus
  PA's `-0.0008492855685796395`.

A shuffled sibling-centroid control changed hard-row margin by
`-0.000042040067125113` relative to PA. A pure positive-only step improved
positive similarity but reduced retrieval margin by `-0.001887250861537014`
relative to PA. A hard-triplet direction produced the largest direct margin
gain (`+0.0047578087571192845` relative to PA), so it is retained as an
explicit non-gating oracle/control rather than hidden.

These values motivated the candidate and cannot satisfy its confirmation gate.

## Operator

For normalized embedding `z_i`, let `S_i` be the other three examples of the
same identity in the frozen 45x4 cohort and define the stopped leave-one-out
centroid

```text
m_i = normalize(mean_{j in S_i} stopgrad(z_j)).
```

The sphere-tangential direction that increases similarity to this centroid is

```text
p_i = (I - z_i z_i^T) m_i.
```

Let `g_i` be the repository's deterministic Proxy Anchor surrogate embedding
gradient, projected into the tangent plane. Ordinary descent is `-g_i`.
Positive cohesion decreases to first order exactly when
`<g_i,p_i> > 0`. LOPS-PG applies the minimum-norm half-space projection

```text
g'_i = g_i                                             if <g_i,p_i> <= 0
g'_i = g_i - <g_i,p_i> p_i / ||p_i||^2               otherwise.
```

Rows with `||p_i|| < 1e-8` are skipped and counted. No denominator floor is
allowed. The projected direction must satisfy `<g'_i,p_i> <= 1e-12` in
float64. For later network training, `g'_i` replaces only the embedding
cotangent for encoder backpropagation. Proxy gradients remain ordinary Proxy
Anchor gradients. Sibling embeddings used in `m_i` are stopped.

The mechanism is a positive-safety constraint, not an extra positive loss: it
changes PA only where PA's descent would locally reduce leave-one-out class
cohesion.

## Alternatives and controls

1. **LOPS-PG (selected):** protects a stable three-sibling centroid and was
   the only discovery arm that improved hard-row margin while making the mean
   positive-similarity change nonnegative.
2. **Nearest-positive safety:** protects the current nearest positive. It was
   active on `99.62%` of discovery rows and improved margin slightly more, but
   still reduced mean positive similarity. It is reported diagnostically.
3. **Hard-triplet replacement:** directly optimizes the measured local margin
   and therefore dominates the one-step diagnostic by construction. It is an
   oracle/control, not a gate LOPS-PG must beat.

The confirmation evaluator includes these arms on identical rows:

- unchanged Proxy Anchor surrogate;
- LOPS-PG;
- shuffled-centroid safety, using a within-cohort derangement generated by
  PCG64 seed `20260821 + cohort_index` and rejecting any same-label assignment;
- pure positive-only descent `-p_i`;
- nearest-positive safety;
- batch-hard triplet descent using the closest positive and closest negative
  under stable example-ID tie breaking.

The shuffled control tests whether any extra orthogonalization helps. The pure
positive control tests whether LOPS-PG is merely positive pulling. The
hard-triplet arm exposes the ceiling of a direction that directly optimizes the
diagnostic and prevents misrepresenting a modest LOPS-PG gain as universally
best.

## Frozen confirmation experiment

The only input is
`inshop_corrected_pa_seed0_train_final.npz`, SHA-256
`67aa387c9815fd300e7db0da9f1a781e4b95191bc9db715e7d06850c9a7e6fea`.
Query and gallery arrays are forbidden inputs.

Reuse the exact LE-IDGP label-fold and cohort construction, but evaluate only
folds 1, 2, and 3. Fold 0 must be rejected by the confirmation CLI. Each cohort
has exactly 45 labels and four rows per label. Normalize archive embeddings and
perform all geometry and aggregation in float64.

Every arm uses the same tangent-normalized single-anchor geodesic step of
`epsilon=0.01` radians while all other cohort embeddings stay fixed. For each
row, record:

```text
margin = max_same_other cosine - max_different cosine
positive_similarity = mean_same_other cosine
```

The frozen primary population in each cohort is the bottom pre-step margin
quartile, selected before computing any arm result with stable example-ID tie
breaking, intersected with nondegenerate `p_i`. All active rows are a secondary
population and cannot rescue a failed primary result.

Cluster bootstrap resamples identities with all their rows using 10,000 PCG64
replicates. Seeds are `20260822` for LOPS minus PA margin, `20260823` for LOPS
minus shuffled, `20260824` for LOPS minus positive-only, and `20260825` for
LOPS minus PA positive similarity. All registered bounds are one-sided 99%
bounds.

## Frozen decision

LOPS-PG passes confirmation only if all conditions hold on folds 1-3:

1. at least 50% of eligible rows conflict, primary rows span at least 100
   identities, and all three folds contain primary rows;
2. pooled primary LOPS-minus-PA margin mean is positive and its one-sided 99%
   lower bound is positive;
3. each of the three fold-level LOPS-minus-PA primary margin means is positive;
4. pooled primary LOPS-minus-shuffled and LOPS-minus-positive-only margin
   contrasts both have positive means and positive one-sided 99% lower bounds;
5. pooled LOPS-minus-PA margin gain is at least 10% of the median absolute PA
   margin change on the same primary rows;
6. pooled LOPS-minus-PA mean positive-similarity contrast is positive and its
   one-sided 99% lower bound is at least `-1e-4`;
7. the actual LOPS direction satisfies the half-space constraint for every
   non-skipped conflicting row, and the unchanged PA direction violates it for
   every row counted as conflicting.

The nearest-positive and hard-triplet arms are reported but non-gating. A
hard-triplet advantage does not kill LOPS-PG because the virtual metric is the
hard-triplet direction's direct objective; any later training trial must still
include an actual batch-hard triplet baseline.

A failed predicate closes this exact leave-one-out centroid, half-space
projection, cohort, step, and population. No threshold, seed, fold, or arm is
changed after reading confirmation output. A pass authorizes only a small
multi-seed training comparison against Proxy Anchor, Proxy Anchor plus a
positive compactness loss, and batch-hard triplet. It does not authorize a
SOTA claim.

## Validation and output

The evaluator writes one canonical JSON report with exact input hash, source
commit, cohort hashes, fold/row/identity counts, conflict and skip counts, every
arm's row-level changes, fold and pooled summaries, bootstrap replicate hashes,
seven ordered predicates, and `PASS` or `KILL`. The validator recomputes all
aggregates, contrasts, bootstrap bounds, and the final decision from persisted
row data. Publication is atomic and no-clobbering. CUDA is hidden and BLAS,
OpenMP, and MKL use one thread.

Tests must cover the finite-difference sign of `p_i`, tangent projection,
non-conflict identity, exact conflict removal, stopped siblings, cohort/fold
exclusion, shuffled derangement, independent arm construction, stable hard
positive/negative ties, identical geodesic distance, cluster bootstrap, every
decision predicate, recursive relation mutations, and canonical JSON reload.

## Prior-art boundary

The ingredients are established:

- Proxy Anchor supplies the base objective and proxy/data interaction:
  https://arxiv.org/abs/2003.13911
- A-GEM and PCGrad establish gradient half-space projection/surgery:
  https://arxiv.org/abs/1812.00420 and https://arxiv.org/abs/2001.06782
- chance-constrained DML uses iterative feasible-set projections and proxy
  coverage, but not this per-example embedding-cotangent constraint:
  https://arxiv.org/abs/2209.09060
- Ranked List Loss deliberately avoids collapsing all positives and preserves
  class structure, whereas LOPS-PG enforces only a local no-decrease condition:
  https://openaccess.thecvf.com/content_CVPR_2019/html/Wang_Ranked_List_Loss_for_Deep_Metric_Learning_CVPR_2019_paper.html
- direction regularization studies pair-displacement geometry but does not use
  this stopped leave-one-out positive half-space:
  https://openaccess.thecvf.com/content_CVPR_2020/html/Mohan_Moving_in_the_Right_Direction_A_Regularization_for_Deep_Metric_CVPR_2020_paper.html

The narrow novelty hypothesis is the per-example spherical projection of a
proxy-loss embedding gradient onto the half-space that preserves similarity to
a stopped leave-one-out same-class centroid, with unchanged proxy updates and
cosine inference. This document does not claim priority; an exact predecessor
search and real training evidence would be required before publication.
