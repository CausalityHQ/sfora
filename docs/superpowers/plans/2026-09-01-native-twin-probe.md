# Matched-Control Native Twin Probe Implementation Plan

**Goal:** Execute the cheapest leakage-safe discriminator of whether native
pixels recover the dominant Cars196 Caliber confusion.

**Spec:** `docs/superpowers/specs/2026-09-01-native-twin-probe-design.md`

### Task 1: Matched-control authority and causal scorer

- RED-test three exact descriptor planes, descriptor-byte custody,
  label-independent image-digest ties, control/native paired predictions,
  independently checked McNemar statistic, full coupled plane-swap
  randomization, every literal gate, canonical bytes, and mutations.
- Keep inference nonparametric and paired; do not fit or repeatedly permute a
  9x-wide LDA on the burned diagnostic population.
- GREEN the focused tests, then run Ruff, pycompile, and diff-check.

### Task 2: Frozen three-plane producer

- Authenticate the seed/checkpoint receipts, source revision/tree, burned-band
  population, decoded RGB namespace, model revision, and processor.
- Before encoding, count decoded RGB digests and remove every member of every
  repeated-pixel group without consulting labels; mutation-lock stable order,
  all-member removal, and rejection of malformed digests.
- Produce global-384, nine fixed two-thirds crops downsampled to a 256px long
  edge, and the same nine crops without that information bottleneck.
- Mutation-lock crop coordinates, downsample/restore behavior, no-op crops,
  long-edge authority, bounded chunked extraction, descriptor order/digests,
  explicit execution, atomic output, and forbidden data/policy flags.

### Task 3: Independent review and repository assurance

- Obtain a read-only adversarial delta review of the repaired six-file slice.
- Run focused core/launcher tests, Ruff, pycompile, and diff-check.
- Commit only the exact spec, plan, core, launcher, and their tests; preserve
  protected untracked operator files.

### Task 4: DGX falsifier

- Wait for the sole seed-43 control campaign to terminate; never overlap or
  duplicate science.
- Run the immutable seed-17 cell from a clean pushed revision. Stop on authority
  or resource failure and preserve one canonical result.
- On pass, replay without parameter changes on seed 29 and then seed 43. On
  failure, reject this fixed native-grid route and prioritize PRISM/data
  evidence rather than another resized-embedding loss.

### Task 5: Conditional verifier only after replicated pass

- TDD a confusion-gated top-two verifier trained only from train-side pairs.
- Then implement fused crop-to-patch and batched pair-attention kernels with a
  scalar reference.
- Gate paired clean improvement, deterministic replay, p95 latency, and memory
  before one fresh sealed evaluation.
