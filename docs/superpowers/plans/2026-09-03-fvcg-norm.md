# FVCG-Norm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and falsify a norm-stabilized semantic-gradient step whose scale is fixed relative to PFML rather than to heterogeneous raw semantic norms.

**Architecture:** A small pure module owns registered arithmetic and canonical evidence. A local-only runner reuses the authenticated Qwen/PFML machinery but captures the two gradient fields independently, combines them in FP32, and performs one existing FP32-master optimizer step.

**Tech Stack:** Python 3.12, PyTorch, pytest, Ruff, existing Sfora Qwen/PFML adapters.

**Spec:** `docs/superpowers/specs/2026-09-03-fvcg-norm-design.md`

## Global Constraints

- Work only in the Sfora repository; do not modify Borsuk.
- `rho` is exactly 0.25 and is never calibrated from observed semantic norms.
- Existing authenticated pair selection, model, prompt, PFML, and resource ceilings remain unchanged.
- Fixture content is frozen independently from source revision.
- Phase A is claim-ineligible and cannot authorize a quality claim.
