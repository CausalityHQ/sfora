# Outcome-only Fable invention round: candidates 368--370

Date: 2026-08-04.

## Corrected isolation

The first attempted continuation revealed that an allow-list naming web tools
does not prevent Claude Code from reading repository files. Fable disclosed
that it had automatically read `HANDOFF_BRIEF.md` and `RSPG_TASK.md`; its
resulting proxy-nullspace proposal was therefore excluded rather than counted.

Candidates 368--370 were run from fresh empty temporary directories with
filesystem, shell, repository search, editing, skills, and agent tools
explicitly disabled. Each saw only the unseen-class retrieval problem, audited
SOTA lanes, corrected local In-Shop references, evaluation rules, and primary
web search. They received no method family, cross-field analogy, candidate
history, or prior Fable output. Proposals were frozen before repository
collision checks.

## Cross-pass failure pattern

Across candidates 365--370, catalogue-blind Fable produced six surface-distinct
proposals but only five occupied operator bundles:

1. subspace decomposition plus relational distillation;
2. uncertainty/quality-aware Euclidean comparison;
3. synthetic composite/virtual classes, generated twice;
4. local-correspondence-to-global distillation; and
5. transferable nuisance synthesis plus covariance metric learning.

None was motivated by a corrected repository measurement that identified its
intervention as outcome-relevant. Two were directly contradicted by prospective
measurements already in the repository. Every proposal estimated component
gains by analogy or addition, despite the project's observed failure of
additivity. Four predicted an absolute score below the audited horizon or
admitted weak odds of clearing it; none supplied reproducible evidence for the
headline number.

This does not prove that a novel outperforming method cannot exist. It does show
that removing catalogue anchoring and method suggestions is not enough: a model
starting from the benchmark headline naturally routes to established
distillation, uncertainty, synthesis, matching, or covariance operators. A
seventh identical prompt has lower expected information than obtaining a new,
prospectively specified outcome-linked measurement or finding a primary-source
error that reopens an occupied family.

## Reopening rule

Further invention becomes actionable only when at least one of these occurs:

- a corrected train-side measurement identifies an observed relation whose
  outcome association survives disjoint-class validation and whose natural
  intervention is not already occupied;
- a primary-source re-audit invalidates a load-bearing prior-art collision; or
- a clean proposal introduces an executable supervision object that cannot be
  typed as weighting, sampling, similarity replacement, regularization,
  distillation, synthesis, uncertainty, local matching, or metric
  preconditioning.

Until then, no GPU arm is licensed by outcome-only invention alone.
