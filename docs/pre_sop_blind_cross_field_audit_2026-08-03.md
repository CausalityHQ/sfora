# Pre-SOP blind cross-field audit

Date: 2026-08-03. Recorded while the corrected official SOP Proxy Anchor run
was still training and before any final checkpoint, embedding pack, structural
diagnostic, or fragmentation result existed. This is a blind horizon audit, not
a candidate registration.

Two independent read-only challenges attacked the stopping boundary from
scientific-mechanism and numerical-acceleration directions. Both were required
to return `NONE` rather than relabel weighting, mining, regularisation,
distillation, a similarity swap, or a generic approximation as a new method.
Neither challenge touched code, files, the GPU, or the queue.

## Scientific-mechanism challenge

The strongest conditional import was phase coexistence: require same-class
samples only to enter a feasible class region, then make positive force zero so
disconnected supports may persist. It is not open:

- Bhatnagar and Ahuja, *Potential Field Based Deep Metric Learning* (CVPR
  2025), already use constant attraction and zero force inside a radius:
  https://openaccess.thecvf.com/content/CVPR2025/html/Bhatnagar_Potential_Field_Based_Deep_Metric_Learning_CVPR_2025_paper.html.
- Wang et al., *Ranked List Loss for Deep Metric Learning* (CVPR 2019), learn a
  class hypersphere while preserving intra-class structure:
  https://arxiv.org/abs/1903.03238.
- Levi et al., *Rethinking Preventing Class-Collapsing in Metric Learning With
  Margin-Based Losses* (ICCV 2021), preserve multiple subclusters through
  nearest-positive selection:
  https://openaccess.thecvf.com/content/ICCV2021/html/Levi_Rethinking_Preventing_Class-Collapsing_in_Metric_Learning_With_Margin-Based_Losses_ICCV_2021_paper.html.

Making the feasible region component-specific becomes positive gating/mining or
multi-centre learning. A chemistry/network alternative that attracts only
cut-critical or effective-resistance edges is occupied by Xu et al., *Deep
Asymmetric Metric Learning via Rich Relationship Mining* (CVPR 2019), whose
within-class minimum-cost spanning tree preserves indirect positive paths:
https://openaccess.thecvf.com/content_CVPR_2019/html/Xu_Deep_Asymmetric_Metric_Learning_via_Rich_Relationship_Mining_CVPR_2019_paper.html.
It also has the wrong causal sign: the registered In-Shop association says
fragmented classes retrieve better, so repairing cuts attacks the observed
structure rather than its defect.

## Numerical-acceleration challenge

The strongest numerical construction was to approximate Proxy Anchor's
exponential sample--proxy kernel with positive random features, replacing a
dense `O(B C d)` interaction by factored `O((B + C) r d)` aggregation. It fails
both opening gates.

At the live SOP dimensions (`B=180`, `C=11,318`, `d=512`), the proxy matrix is
about 1.04 billion multiply-accumulates per batch (2.09 GFLOP under the usual
two-operations convention) and is small beside 180 BN-Inception
forward/backward passes. A five-sample live utilization check showed 82--95%
GPU SM use, but no operator-level profile identifies the proxy matrix as the
wall-clock bottleneck. Thus the repository supplies no Gate-1 speed defect.

The numerical mechanism is also established by random-feature softmax and
exponential-kernel work, including Rawat et al., *Sampled Softmax with Random
Fourier Features* (NeurIPS 2019),
https://papers.nips.cc/paper_files/paper/2019/hash/e43739bba7cdb577e9e3e4e42447f5a5-Abstract.html,
and Reid et al., *Simplex Random Features* (ICML 2023),
https://proceedings.mlr.press/v202/reid23a.html. Tree pruning, ANN selection,
sampling, Nyström, and coresets reduce to established screening, PartialFC,
hard-negative mining, or generic approximation.

## Blind verdict

**No candidate survives before corrected SOP artifacts.** Fragmentation alone
cannot reopen connectivity repair, class shells, diversity, or multi-centres.
Proxy count alone cannot reopen sampled/approximated softmax. The search may
reopen only if independently verified SOP measurements expose a new observable
beyond generic multimodality/class geometry, or a measured runtime bottleneck
with structure not covered above.
