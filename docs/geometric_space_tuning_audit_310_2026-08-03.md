# Geometric space-tuning audit (candidate 310)

The new search branch attacked anisotropic and manifold-valued similarity rather
than another positive-selection rule. The corrected In-Shop/SOP geometry gap and
the requested “space tuning” direction motivated the branch, but no new measured
effect authorized GPU work.

Gate 2 is dead before implementation. Nonlinear rank-approximation similarities
([Schall et al., 2019](https://arxiv.org/abs/1909.09427)), divide-and-conquer
subspace metrics ([Sanakoyeu et al., CVPR 2019](https://openaccess.thecvf.com/content_CVPR_2019/papers/Sanakoyeu_Divide_and_Conquer_the_Embedding_Space_for_Metric_Learning_CVPR_2019_paper.pdf)),
structural/optimal-flow matching ([Zhao et al., ICCV 2021](https://openaccess.thecvf.com/content/ICCV2021/html/Zhao_Towards_Interpretable_Deep_Metric_Learning_With_Structural_Matching_ICCV_2021_paper.html)),
class-covariance Mahalanobis metrics (FeCAM, [Kao et al., NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/file/15294ba2dcfb4521274f7aa1c26f4dd4-Paper-Conference.pdf)),
directional/vMF class distributions ([Zhang et al., 2019](https://doi.org/10.1016/j.patcog.2019.06.012)),
spherical embedding constraints ([Zhang et al., NeurIPS 2020](https://proceedings.neurips.cc/paper/2020/hash/d9812f756d0df06c7381945d2e2c7d4b-Abstract.html)),
and soft orthogonal proxies ([Roth et al., 2023](https://arxiv.org/abs/2306.13055))
occupy the proposed operators. A train-fitted linear projection is already
measured in this repo and provides compression, not a quality gain. No
implementation, diagnostic, preregistration, or GPU run follows.
