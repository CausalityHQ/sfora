# Candidate 231: sliced quantile token embedding (SQTE)

Date: 2026-08-02. Status: **DEAD at Gate 2; Gate-1 provenance corrected**.
No diagnostic, implementation, or GPU.

SQTE proposed projecting each final convolutional token onto shared directions,
sorting responses over spatial positions, sampling fixed quantiles, and mapping
the concatenated order statistics into part of the deployed 512-dimensional
cosine embedding. A global-average branch would be retained.

## Gate 2

The core operator is prior art. Naderializadeh, Kolouri, Comer, Andrews and
Hoffmann, *Set Representation Learning with Generalized Sliced-Wasserstein
Embeddings* (arXiv:2103.03892, 2021), represents a permutation-invariant set by
projecting it onto slices and encoding the empirical one-dimensional quantile
functions. Euclidean distance of those representations approximates a
Sliced-Wasserstein distance. Learned or nonlinear slices are the subject of
Kolouri et al., *Generalized Sliced Wasserstein Distances* (NeurIPS 2019).

The proposed linear mixing and cosine are a downstream metric choice, not a new
set representation. Fixed/learned directions remain permutation invariant
because they are shared across positions before sorting. Replacing quantiles by
top-k values gives SortPooling; soft bins give learnable histogram/Deep TEN;
residual statistics give Fisher/VLAD/NetVLAD; second moments give bilinear or
covariance pooling. No narrow variant survives as a novel mechanism.

## Gate-1 correction

The motivating `+6.67` was misdescribed during generation. It is not a frozen
token result: an already-trained `region_pa` model scored `0.5775` when evaluated
with fixed-slot concatenated cosine and `0.6442` after its evaluation was aligned
with the MaxSim-like training score. The three-seed region model still averaged
`0.6466`, 3.6 points below Proxy Anchor. That comparison distinguishes a
position-sensitive metric from correspondence-based MaxSim; it does not
distinguish global mean pooling from quantile pooling, both position invariant.

The actual frozen readout probe in `scripts/probe_late_interaction.py` used Cars
and found global `0.8306` versus MaxSim `0.8159`, a **1.47-point loss**. The
repository therefore has no positive measurement showing that token-distribution
statistics retain identity evidence absent from the global mean.

No CPU diagnostic is authorized after the novelty death. In any event, a valid
future token-distribution diagnostic would require a matched `(N,P,C)` token
pack, labels, and global vectors from the same forward pass; no such local pack
is tracked in this worktree.
