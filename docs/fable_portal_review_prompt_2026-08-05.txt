## 1. Executable mathematics

Test: resize 256, center crop 224, one view, cosine 1-NN. No reranking, no query expansion, no test-gallery statistics. Learned objects are exactly $\theta$ and $E$; PORTAL adds **zero** learned parameters and **no** proxy matrix.

**Batch.** $P{=}28$ classes × $K{=}4$ images, $B{=}112$; RandomResizedCrop(224) + horizontal flip only. A cross-batch memory queue $\mathcal{M}$ of $M{=}4096$ L2-normalized embeddings with labels, no gradient, FIFO, filled during a 1-epoch warmup. **The queue is held identical in both arms of every comparison**, so the claim is never "more negatives."

**Similarities.** $s_{ij}=\hat z_i^\top \hat z_j$. For anchor $i$: positives $\mathcal{P}(i)$ in-batch, negatives $\mathcal{N}(i)=\{j\in\text{batch}\cup\mathcal{M}: y_j\neq y_i\}$, so $|\mathcal{N}(i)|\approx 4200$.

**Positive score** (R@1 needs the *best* positive to win), $\beta{=}8$:

$$s_i^{+}=\tfrac{1}{\beta}\log\tfrac{1}{|\mathcal{P}(i)|}\textstyle\sum_{j\in\mathcal{P}(i)}e^{\beta s_{ij}}$$

**Peaks-over-threshold model.** Fix exceedance fraction $p=0.05$. Let $u_i$ be the empirical $(1-p)$-quantile of $\{s_{ij}\}_{j\in\mathcal{N}(i)}$ (gradient flows to the selected order statistic). Pool anchor-centered excesses $y=s_{ij}-u_i>0$ across all anchors: $m\approx 0.05\cdot 112\cdot 4200\approx 2.4\times10^{4}$ exceedances per step. Fit **one shared** $(\xi,\sigma)$ by probability-weighted moments (Hosking–Wallis), closed-form and differentiable — no inner optimization:

$$a_0=\tfrac1m\sum_k y_{(k)},\qquad a_1=\tfrac1m\sum_k y_{(k)}\Big(1-\tfrac{k-0.35}{m}\Big),$$
$$\hat\xi = 2-\frac{a_0}{a_0-2a_1},\qquad \hat\sigma=\frac{2a_0a_1}{a_0-2a_1}.$$

(Check: an exact exponential tail gives $a_0=\sigma$, $a_1=\sigma/4$, hence $\hat\xi=0$, $\hat\sigma=\sigma$.) Guard $a_0-2a_1\ge\varepsilon_a=10^{-4}$; clip $\hat\xi$ to $[-1,0.4]$ **inside the return-level term only**, leaving it unclipped in the anchor term below.

**Return-level loss.** The deployment scale $N$ is set to the **number of training images** $N_{\mathrm{tr}}$ — a legitimate deployment design parameter that uses no test information. (Using the benchmark's gallery size would be a protocol violation; I do not.) With $\bar F_i(s_i^+)=p\big(1+\hat\xi\,(s_i^+-u_i)_+/\hat\sigma\big)_+^{-1/\hat\xi}$ and $\Lambda_i=N\bar F_i(s_i^+)$ = expected count of gallery false positives above the best positive:

$$\mathcal{L}_{\mathrm{ret}}=\tfrac1B\textstyle\sum_i \log(1+\Lambda_i).$$

If $s_i^+\le u_i$ the anchor is in the bulk-failure regime and $\bar F_i$ falls back to the smooth empirical exceedance $\tfrac{1}{|\mathcal{N}(i)|}\sum_j\varsigma\big((s_{ij}-s_i^+)/0.01\big)$, $\varsigma$ = sigmoid. Since $\Pr[\text{R@1 error}]\approx 1-e^{-\Lambda}$, $\log(1+\Lambda)$ is the well-conditioned monotone surrogate.

**Tail-index anchor.** For $z,z'$ i.i.d. uniform on $S^{d-1}$, $f(s)\propto(1-s^2)^{(d-3)/2}$, so $\bar F(1-\epsilon)\propto\epsilon^{(d-1)/2}$, putting the upper tail in the reverse-Weibull domain with

$$\boxed{\ \xi^\star=-\tfrac{2}{d-1}=-0.003914\ \text{ for } d=512\ }$$

a closed-form target fixed entirely by the deployed descriptor dimension. With $h_\delta$ = Huber ($\delta{=}0.2$, linear beyond, so gradients are bounded but never vanish):

$$\mathcal{L}_{\xi}=h_{0.2}\!\left(\hat\xi-\xi^\star\right).$$

**Positive term, capped to forbid within-class collapse** ($\gamma{=}32$, $\delta_p{=}0.5$):

$$\mathcal{L}_{\mathrm{pos}}=\tfrac1B\sum_i\tfrac{1}{|\mathcal{P}(i)|}\sum_{j\in\mathcal{P}(i)}\tfrac1\gamma\,\mathrm{softplus}\big(\gamma(\delta_p-s_{ij})\big).$$

Pull stops once a positive pair exceeds 0.5; $\delta_p\to1$ restores full collapse pressure and is an ablation.

$$\mathcal{L}=\mathcal{L}_{\mathrm{ret}}+\lambda_p\mathcal{L}_{\mathrm{pos}}+\lambda_\xi\mathcal{L}_\xi,\qquad \lambda_p=1,\ \lambda_\xi=10.$$

**Gradient path.** Gradients reach $\theta,E$ through $s_{ij}$ (four routes: $s_i^+$, $u_i$, $a_0$, $a_1$), so the loss has support on all ~2.4×10⁴ exceedance pairs per step, not on a single mined hardest negative. Differentiating, $\partial_x\log(1+\Lambda)=-\Lambda\big/\big[(1+\Lambda)\sigma(1+\xi x/\sigma)\big]$ with $x=s_i^+-u_i$: magnitude $\to 1/\hat\sigma$ when $\Lambda\gg1$ and $\to\Lambda/\hat\sigma$ when $\Lambda\ll1$. Anchors already safe *at gallery scale* receive no gradient — hardness weighting derived from deployment scale, not from relative similarity.

For $d{=}512$ the isotropic tail is nearly exponential ($\xi^\star\approx-0.004$, finite endpoint at $x=-\sigma/\xi\approx12.8\gg2$), so $\mathcal{L}_\xi$ never binds through $\mathcal{L}_{\mathrm{ret}}$ — I state plainly that it acts **purely as a non-degeneracy anchor**, and control C5/F5 tests exactly that.

## 2. Causal zero-shot error mode, and a proof-level attack on the cheap degeneracies

**Error mode — gallery-scale extremal mismatch.** For query $i$ against $N$ negatives, $\Pr[\text{R@1 err}]\le N\bar F_i(s_i^+)$: R@1 is governed by the **far upper tail** of the negative-similarity law, at exceedance level $\sim1/N$. Proxy and softmax losses saturate once the anchor beats its $C_{\mathrm{tr}}$ proxies, i.e. they control the tail only down to level $\sim1/C_{\mathrm{tr}}$. The mismatch is $N_{\mathrm{tr}}/C_{\mathrm{tr}}$: **59× on CUB, 82× on Cars, but only 6.5× on In-Shop and 5.3× on SOP**. Nothing in the training signal shapes the region that decides retrieval on fine-grained benchmarks. This yields a mechanism-specific, falsifiable ordering (§5) that no generic regularizer predicts.

**Degeneracy attacks.**

*Constant embedding.* $\hat z\equiv c$ ⟹ all $s_{ij}=1$ ⟹ $u_i=1$, $s_i^+=u_i$, empirical branch gives $\bar F_i=1$, $\Lambda_i=N$, $\mathcal{L}_{\mathrm{ret}}=\log(1+N)\approx 8.7$–$11$. Collapse is the **global maximum**, not a minimum.

*Neural collapse / simplex ETF — the expensive one, killed exactly.* The terminal-phase solution puts all training negatives at $s=-1/(C-1)$ with zero spread. Then every excess equals some $y_0$, so $a_0=y_0$ and $a_1=y_0\cdot\frac1m\sum_k(1-\frac{k-0.35}{m})\to y_0/2$, hence $a_0-2a_1\to0^+$ and

$$\hat\xi = 2-\frac{y_0}{0^+}\ \longrightarrow\ -\infty .$$

**The PWM tail-index estimator diverges to $-\infty$ precisely on atomic similarity distributions, which is the neural-collapse configuration.** With the Huber anchor this is a linearly-growing penalty with non-vanishing gradient, so the ETF minimizer that every proxy/softmax loss admits is structurally excluded here. This is the load-bearing property of the method and the reason $\mathcal{L}_\xi$ is not a cosmetic regularizer.

*Threshold gaming.* $u_i$ is the **upper** 95th percentile, set by the hardest 5% of negatives. Pushing easy negatives further away cannot lower it; only improving the hard tail can. No shortcut.

*Scale gaming.* $\mathcal{L}_{\mathrm{ret}}$ prefers small $\hat\sigma$ (tight negative tail), $\mathcal{L}_\xi$ forbids the atomic limit that small $\hat\sigma$ approaches. The two terms are in designed tension; the feasible set is "clustered bulk, isotropically-shaped near-collision geometry" — exactly the trade zero-shot retrieval wants, since novel classes live in the interstices.

*Unfixable within the rules, declared.* All negatives are training-class negatives. If seen and unseen tail shapes differ materially, transfer is weaker. Partial mitigation: $\xi^\star$ is a purely geometric, label-free target.
