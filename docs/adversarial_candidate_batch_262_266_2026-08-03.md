## Provenance and outcome

The generation pass used only persisted repository observations: ARCG's selective
augmentation-response relation, In-Shop proxy/centroid ownership asymmetry and class
sizes, and CUB cross-class ANOVA structure. Those structural observations remain exact
for their archived runs but were generated under recipe deviations discovered later;
none can be promoted to faithful-upstream effect evidence. No candidate uses the
retracted leave-neighbour pseudo-correction.

The batch independently converged on the same boundary as candidate 229: without a new
observed node or relation, an equivariant update over embeddings, views, teachers,
memory, and proxies changes only weights, mining, aggregation, or regularization. The
corrected SOP final artifacts are still the legitimate reopening point because they
will provide the first faithful measurements in a third class-semantic regime. This is
an evidence-bounded negative, not an impossibility theorem.
