# SOP true-freeze public-config official TEST gate, frozen before new read

The existing official TEST receipts export batch-64 FP32-weight/FP16-autocast descriptors. The public default serves at batch up to 32 with FP16 weights, and exact descriptor parity failed. The six prior checkpoints, official TEST inventory and same-source paired decisions remain fixed. This gate measures a **new deployment candidate**: both gallery and query descriptors exported at batch 32 through the exact public FP16 encoder arithmetic. It is exploratory because SOP TEST was previously observed by Sfora. No SOTA claim or checkpoint/seed selection follows.

Use the pinned SigLIP2 Large/256 snapshot, 128-D head, official 60,502-image/11,316-product TEST manifest SHA-256 `28a3ec0561cd83ee426f3d1c301c70799316af91c1e9083a5a1ffdf3414327c1`, source archive SHA-256 `1ba27b2d6b9db39067aa6facd0ef8aafc303c4527f6feabed859b0512c7d921a`, and native scorer SHA-256 `39602d0e4e8b0d5ec441be460ad7f18e288241bef19fb6e6c5df14f4033ac73c`. Load each seed's existing control then freeze checkpoint and its prior paired TRAIN decision; run seeds 179024, 179026, 179027 serially, one pair at a time on DGX Spark GB10. Export all TEST images with FP16 vision weights, half pixel input, no autocast, FP32 head, batch 32. Before scoring, require exact packed code and inverse-norm equality between the first 32 exported descriptors and `Siglip2CompactEncoder.encode_images` on those same pinned images. Score symmetric full-gallery packed R@1 and mAP@R with self excluded and stable ordinal ties; require exact native top-10 and per-query R@1 parity, and record per-query vectors, source/runtime/checkpoint/image/scorer hashes, export/score wall and resource peaks.

For each seed, freeze packed R@1 and mAP@R point estimates must each be at least same-seed control, and the paired product-bootstrap 95% lower bound on R@1 must exceed −0.5 percentage points. Stop before the next seed if a pair fails. Passing all three would validate an exploratory official-quality result for this **batch-32 FP16 gallery/query configuration**, not the currently stored batch-64 TRAIN gallery or the public index's ability to load arbitrary galleries. Promotion additionally requires a production external-gallery authority path and its exact loader parity check. The completed matched public FP16 batch-1/batch-32 latency receipt is a separate diagnostic; p99 remains unqualified.

## Seed 179024 result

The first same-source pair passed on DGX Spark GB10. The public encoder reproduced the first 32 packed exported descriptors exactly in both arms; native top-10 and per-query R@1 matched the full packed oracle. Frozen versus control packed R@1 was **91.6664% vs 91.2433%** (+0.4231 percentage points, paired product-bootstrap 95% interval **[+0.2699, +0.5835] points**); mAP@R was **0.767652 vs 0.756689**. Export wall was 414.02 versus 413.50 seconds for all 60,502 TEST images. Raw receipts, decision and service journal are in `docs/evidence/compact_metric/sop-siglip2-substrate-v1/sop-true-freeze-public-official-179024/`. This passes the frozen exploratory gate and permits seed 179026; it does not certify the current batch-64 TRAIN gallery or a SOTA claim.

## Production gallery loader check

The public `Siglip2CompactIndex.from_artifacts` now accepts a separately SHA-256-pinned official receipt and descriptor file, verifies their training receipt, checkpoint, native scorer, precision, batch, shape and descriptor digest, then opens the exact native gallery. A seed-179024 frozen production check loaded the 60,502-row FP16 TEST gallery and queried the first 32 pinned images through `search_images`. All 32 packed query codes and inverse norms equalled the evaluator export, and all 32 native top-10 ordinals and scores equalled the full packed oracle exactly (maximum score delta 0.0). Receipt SHA-256: `6c77427e32c5e4bef7c07b4452fad47bfcb96b401d9959509565778350bd0d78`; raw receipt and systemd journal: `docs/evidence/compact_metric/sop-siglip2-substrate-v1/sop-true-freeze-official-loader-179024/`. This is a production-path parity check, not a new independent quality sample or p99 measurement. The arbitrary user gallery path and full image-to-top-10 latency with this TEST gallery remain separate product work.

An independent terminal review found that the first verifier did not pin the imported implementation or manifest and could accept nonfinite native scores. The corrected verifier requires the exact imported serving, packing, training-head and native-wrapper source hashes, the full TEST archive and image-manifest hashes, finite native scores, and JSON without NaN. It reran the same 32-image production query on DGX Spark GB10 with exact codes/norms/top-10 and zero score delta; the [v2 receipt](evidence/compact_metric/sop-siglip2-substrate-v1/sop-true-freeze-official-loader-179024-v2/receipt.json) has SHA-256 `a90dd07fb0ffb06b075c6f0aa81f465a715884406a7758c1677e4343cf8b6667`, with its [journal](evidence/compact_metric/sop-siglip2-substrate-v1/sop-true-freeze-official-loader-179024-v2/service-journal.txt) beside it. The official evaluation receipts bind an earlier encoder module SHA, but the new loader module's encoder path is unchanged and v2 binds the loaded source SHA `700fd6d1e045e135c5298fd8842f6275e68bdd3cec9a158790aa8dce9267c614`. This still verifies only one seed's first 32 same-batch gallery images. Batch-1 and mixed-batch query quality, arbitrary external galleries, and p99 remain unqualified.
