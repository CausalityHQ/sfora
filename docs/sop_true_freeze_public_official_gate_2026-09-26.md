# SOP true-freeze public-config official TEST gate, frozen before new read

The existing official TEST receipts export batch-64 FP32-weight/FP16-autocast descriptors. The public default serves at batch up to 32 with FP16 weights, and exact descriptor parity failed. The six prior checkpoints, official TEST inventory and same-source paired decisions remain fixed. This gate measures a **new deployment candidate**: both gallery and query descriptors exported at batch 32 through the exact public FP16 encoder arithmetic. It is exploratory because SOP TEST was previously observed by Sfora. No SOTA claim or checkpoint/seed selection follows.

Use the pinned SigLIP2 Large/256 snapshot, 128-D head, official 60,502-image/11,316-product TEST manifest SHA-256 `28a3ec0561cd83ee426f3d1c301c70799316af91c1e9083a5a1ffdf3414327c1`, source archive SHA-256 `1ba27b2d6b9db39067aa6facd0ef8aafc303c4527f6feabed859b0512c7d921a`, and native scorer SHA-256 `39602d0e4e8b0d5ec441be460ad7f18e288241bef19fb6e6c5df14f4033ac73c`. Load each seed's existing control then freeze checkpoint and its prior paired TRAIN decision; run seeds 179024, 179026, 179027 serially, one pair at a time on DGX Spark GB10. Export all TEST images with FP16 vision weights, half pixel input, no autocast, FP32 head, batch 32. Before scoring, require exact packed code and inverse-norm equality between the first 32 exported descriptors and `Siglip2CompactEncoder.encode_images` on those same pinned images. Score symmetric full-gallery packed R@1 and mAP@R with self excluded and stable ordinal ties; require exact native top-10 and per-query R@1 parity, and record per-query vectors, source/runtime/checkpoint/image/scorer hashes, export/score wall and resource peaks.

For each seed, freeze packed R@1 and mAP@R point estimates must each be at least same-seed control, and the paired product-bootstrap 95% lower bound on R@1 must exceed −0.5 percentage points. Stop before the next seed if a pair fails. Passing all three would validate an exploratory official-quality result for this **batch-32 FP16 gallery/query configuration**, not the currently stored batch-64 TRAIN gallery or the public index's ability to load arbitrary galleries. Promotion additionally requires a production external-gallery authority path and its exact loader parity check. The completed matched public FP16 batch-1/batch-32 latency receipt is a separate diagnostic; p99 remains unqualified.
