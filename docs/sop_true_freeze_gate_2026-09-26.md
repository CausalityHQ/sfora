# SOP true lower-stack freeze transfer gate, 26 September 2026

In-Shop seed 179024 showed that freezing SigLIP2 Large/256 patch/position embeddings and vision blocks 0–11 reduced training wall and VRAM materially while packed top-1 differed from full control by one query and mAP@R rose. The frozen In-Shop point-estimate gate failed, so this is a distinct **SOP transfer test**, not a retry or promotion of that result. The asymmetric In-Shop diagnostic failed its own usefulness threshold and has no selection authority.

The SOP comparison uses official **TRAIN only**: 53,700 fit images in 10,186 products and 5,851 held query images in 1,132 unseen products. The evaluation gallery contains all 59,551 TRAIN images, self excluded, as in the existing SOP trainer. It differs substantially from official TEST and has informed prior selection. Use seed 179024, SigLIP2 Large/256, the same 128-D head, ArcFace plus detached full-fit member-bank SmoothAP coefficient 8, BF16 vision, coverage-first identity batches, 1,000 updates, identical optimizer/augmentation, native exact 130-byte packed scorer and one immutable source checkout. Run a serial control and `--freeze-lower-stack` treatment from the same source, preflight, feature cache, model and schedule. The flag freezes only vision embeddings and blocks 0–11; upper blocks, pooling, post-layer norm, head and classifier remain trainable.

Frozen gate before new quality results:

1. Run 17-update control and treatment smokes serially on DGX Spark GB10. Require identical first-ten input, schedule, model, cache, PCA, source and split hashes, finite losses and optimizer steps, and treatment checkpoint embedding/lower-block tensors bit-identical to the pinned pretrained model while upper/head/classifier tensors change. Advance only if treatment training wall and peak allocated CUDA are each at least **10% below** the paired smoke control. The older coverage-first receipt is context, not a same-source control.
2. If smoke passes, run exactly one serial 1,000-update control/treatment pair and evaluate the unchanged TRAIN holdout with exact native packed-score parity. Advance only if treatment packed Recall@1 point is at least control, the paired product-bootstrap 95% lower bound is greater than **−0.5 percentage points**, mAP@R is at least control, training wall including bank initialization is at least **15% lower**, and peak allocated CUDA at least **20% lower**. Require complete finite steps, checkpoint/source/resource hashes and per-query vectors. If any gate fails, stop before further seeds and official TEST.
3. A passing seed remains exploratory. Freeze a seed-aware independent confirmation protocol on fresh seeds 179026 and 179027 before considering the training option for production. Serving storage, scorer and image-to-top-k path are unchanged by construction; measured serving latency is a separate gate.

Historical seed-179024 coverage-first bank context (older trainer source) was **92.3090% packed Recall@1**, **0.767332 mAP@R**, **1,150.388 s** per 64,000 sampled images and **21.409 GB** peak allocated CUDA. It is not substituted for the new same-source control. No official or SOTA inference follows from this TRAIN-only screen.
