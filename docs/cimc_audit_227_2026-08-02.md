# Candidate 227: cross-instance masked completion (CIMC)

Date: 2026-08-02. Status: **DEAD at Gate 2**. No diagnostic,
implementation, or GPU.

## Gate 1

CIMC passes provenance. In-Shop PA has within-acquisition cosine `0.8199`
versus cross-acquisition `0.6396`; 90.90% of nearest neighbours share the
acquisition token; and the exact PA positive gradient amplifies this gap. The
proposal masks tokens in one training image and gives a lightweight decoder
visible target tokens plus stop-gradient tokens from a different same-class
image. The decoder predicts the missing target tokens and is discarded at test.
This attempts to add cross-instance conditional evidence rather than another
scalar edge weight.

## Gate 2: the exact object is occupied

CroCo (Weinzaepfel et al., NeurIPS 2022), *Self-Supervised Pre-Training for 3D
Vision Tasks by Cross-View Completion*, masks one image and uses cross-attention
to a second view to reconstruct it. CrossTransformers (Doersch et al., NeurIPS
2020) reconstructs query tokens as attention-weighted combinations of
same-class support-image tokens. The occluded person-reidentification line,
including Hou et al., *VRSTC* (CVPR 2019) and *Feature Completion for Occluded
Person Re-Identification* (TPAMI), completes missing region features using
other observations of an identity. These occupy both the architecture and the
same-identity conditioning claim. Latent target variants are additionally
inside data2vec, I-JEPA, SiameseIM, BootMAE, and related masked-feature
prediction.

Let target tokens be `T_i`, visible tokens `V`, masked set `M`, stopped context
`C=sg[f(x_j)]`, and decoder `g`. Under squared loss the optimal decoder is
`E[T_i,M | V,C]`; the only addition over single-image masked prediction is the
conditional information `I(T_i,M; C | V)`. The corresponding gradient is
cross-image feature regression with a learned dense correspondence—region-wise
distillation/attraction. If the completion residual is later used to decide a
pair, it becomes the already-occupied gating/weighting operator.

## Why the measured nuisance makes the mechanism worse

For two distinct same-label images, shared predictable information is:

1. the class identity already supplied to Proxy Anchor;
2. shared acquisition, view, lighting, or background nuisance; or
3. physical instance appearance, which exists for an In-Shop identity but not
   for a CUB species class.

The conditional information is largest for same-acquisition pairs, so CIMC
rewards the channel it was meant to remove. Forcing cross-acquisition partners
reduces that conditional information and makes the loss revert toward ordinary
single-image masked modeling. On CUB, where class is not physical instance, an
MSE predictor of image-specific missing content collapses toward the
class-conditional token mean—dense prototype attraction. Thus the mechanism
cannot both address the measured shortcut and transfer to the second dataset.

The result is not rescued by pixel targets, learned discrete codes, allowing
gradients through both images, or using the residual as a gate: these map to
MAE/CroCo, iBOT/BEiT, pair attraction/CCA, and positive mining respectively.
The train-only decoder deployment story is also established by auxiliary-branch
DML such as S2SD and DiVA. No diagnostic is warranted because every possible
completion-quality outcome feeds an occupied operator.
