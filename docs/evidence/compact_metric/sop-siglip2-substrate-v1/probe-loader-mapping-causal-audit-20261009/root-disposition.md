The five stdlib cases execute unmodified extracted loader, copy, mapping and cleanup seams with real mmap and fake tensor/native dependencies. Root independently checked all three source digests against current committed files and the recorded case distinctions. This is mechanism evidence, not a native reproduction or attribution.

A head exception after independent copying retains its original error and passes the mapping check. Neither copying itself nor every exception is therefore established as the native cause.
