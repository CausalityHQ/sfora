# Installed Python source loader contract

The prospective parity qualifier needs a finite source loader, not another environment installation tool. Own only `scripts/connected_installed_source_guard.py` and its source-only test. Existing library/factory/native/math code stays unchanged. Inputs are independently authenticated exact source/resource FILE rows, explicit installed roots, explicit namespace locations, and pinned interpreter stdlib roots. The static graph is a candidate pool, never automatically the input authority.

Reuse genuine `PathFinder` resolution and `SourceFileLoader` package semantics. Before loading an installed source, require its resolved origin and package path to match the finite authority. Override only source-code acquisition: freshly read canonical regular bytes, verify original size/SHA, and compile those bytes directly, without reading or writing a `.pyc`. Loader `get_data` reads require exact finite rows. Other filesystem APIs, including `importlib.resources` paths, require the outer qualifier's independently authenticated I/O audit; this finder is not an I/O sandbox. Recheck source bytes after execution and loaded module/loader/spec/package/namespace identities at exit. Do not overwrite, adopt or delete foreign registry entries.

Unknown installed source, old-environment fallback, bytecode-only origin, undeclared namespace, path/spec drift and source mutation reject. Native extension origins outside the pinned stdlib are rejected by this component; a separately authenticated finite native finder must handle its declared extensions before this finder. There is no native permission callback, broad `.so` exception, distribution-root read grant, or modified original native predicate. The complete native gate remains mandatory. Stdlib origins fall through to the existing pinned interpreter policy and genuine native audit.

Tests use tiny actual Python source packages and genuine stdlib import machinery. Run one affected source-only suite under 120 seconds / AS 1 GiB after focused tests. Real Torch/NumPy/PIL/native/image/payload work is prohibited locally.
