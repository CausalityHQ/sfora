# Pass 155 — independent Codex fresh invention review (NONE)

## Scope

This was a cold, read-only cross-model review after Pass154. It was given the
verified repository boundary and asked for exactly one train-time DML method
only if it had both a measured Gate-1 premise and a mechanism-level novelty
distinction at Gate 2. Fable and its Claude fallback were unavailable because
of the weekly provider limit; this pass records the Codex fallback.

## Result

**NONE.** The strongest apparent escape was to preserve pairwise ratios of the
512-D embedding against the In-Shop texture-residual signature. The registered
category-disjoint diagnostic measured held-out incremental AUC **+0.001195**,
far below the **+0.05** provenance threshold (about 42 times too small). The
clean train-time realization is continuous auxiliary-distance/relations
matching, which is mechanism-equivalent to Kim et al., *Deep Metric Learning
Beyond Binary Supervision* (arXiv:1904.09626) and overlaps S2SD (Roth et al.,
ICML 2021). Replacing pose or feature labels with texture does not create a
new training object.

The review also judged the one-seed CIS dropout result (+0.056 raw, +0.042
final) too weak and already inside a closed coalition family. No CPU
diagnostic, implementation, or GPU run is authorized by this pass.

## Boundary

This is a negative search result, not proof that no future mechanism can exist.
The next candidate must be grounded in a newly measured independent signal; it
must not be manufactured by repackaging the failed residuals or by renaming an
occupied relation-matching loss. Full context is in
`docs/pass153_texture_residual_preregistration_2026-08-08.md` and
`docs/pass152_sol_fresh_search_2026-08-08.md`.
