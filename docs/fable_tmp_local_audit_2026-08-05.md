# Candidate 376: Tied-Mode Proxies local resolution

Date: 2026-08-05.

Frozen proposal: `docs/fable_tmp_proposal_pass12_2026-08-05.md`.
Independent review: `docs/fable_tmp_review_2026-08-05.md`.

The independent reviewer returned **LIVE** but established two defects that are
decisive under `docs/search_protocol.md`: the objective is invariant to
class-specific mode semantics, and it admits a loss-reducing class-group coding
shortcut. The local verdict is therefore **DEAD at Gates 1 and 2/formal audit;
no GPU**. Model agreement is not evidence, and a reviewer cannot waive the
protocol's requirement that the objective exclude its named cheap shortcuts.

## Gate 1: no identified shared-mode provenance

The verified corrected In-Shop packet contains repeatable fragmentation and
persistent errors, but not shared pose/view modes. The deeper preregistered
audits found fragmentation aligned strongly with acquisition-series structure,
not view descriptors, and the retrieval association reversed under nearest-
partner deletion; the final conclusion was **causally unidentified**, not a
mode-transfer effect. The official split also lets 95.604% of queries retrieve a
same-series positive and 42.720% have only same-series positives. Thus the
proposer's claim that cross-class shot modes are the canonical error source is
plausible armchair structure, not an eligible measured causal premise.

## Formal failure

For each class, the loss sees only the unordered set of `K` proxy similarities:

```
S_c(z) = beta^-1 log mean_k exp(beta <z, p_ck>).
```

It contains no cross-class correspondence saying that index `k` has the same
meaning for two identities. Balanced global usage is invariant to balanced
class-specific permutations. More strongly, each class can route all examples
to one `r_k`, with approximately `C/K` classes assigned to each offset. This
satisfies global balance and uses the shared offsets as coarse class-group
separators, increasing margins without representing any within-class mode.
That is a favorable shortcut, not a rare degenerate stationary point.

The frozen C7 audit cannot repair the training object. It defines modes from
TMP's own learned offsets and leaves the C2 comparison partition unspecified;
it can therefore register ordinary compactness as the claimed transfer. A
post-hoc detector of a shortcut is not an exclusion proof. Repairing the loss
with cross-class correspondence supervision, per-class usage constraints, or a
budgeted-untied decisive cell changes the frozen proposal and must restart
generation.

The D1 margin proof is also wrong by roughly a factor of two: a between-class
margin contains residual perturbations from both class proxies, permitting
about 0.18 rather than 0.09 cosine units, close to `2 delta = 0.2`.

## Gate 2 neighborhood

The exact proxy parameterization may be unreported, but its claimed mechanism—
learning class-shared intra-class transformations that transfer to unseen
identities—is occupied by MIC's class-shared characteristics, FATTEN's
transferable pose trajectories, Densely-Anchored Sampling's Memorized
Transformation Shifting, GroupFace's latent groups, and the older tied-factor/
PLDA identity-versus-variation models. The proposal changes where the shared
factors are parameterized, while its loss supplies no new observation aligning
them. That implementation distinction cannot rescue the false forcing claim.

The reviewer correctly noted a missing budgeted-but-untied control. A gain could
come solely from proxy norm/elastic regularization while satisfying the frozen
decision rule, so even a positive aggregate result could not identify tying.

Verdict: **DEAD.** No preregistration, implementation, or GPU follows.
